# Module 1 real-data evaluation

The read-only PostgreSQL run finished on November 16, 2026, using a source cutoff of **2026-11-16 14:00 Asia/Karachi**. The configured server initially refused connections. The read-only SQLite audit found 475,244 price records across 100 tickers and only legacy ANNUAL and QUARTERLY financial imports. PostgreSQL subsequently became reachable and supplied the training dataset.

The filing audit flagged 149 unmatched periods, two with ambiguous releases and 21 with incomplete core financials. Date-only release evidence came from matching PSX_DPS annual-report transmission announcements. The underlying financial values came from the database's IFRS snapshot. The module excluded the legacy imports and calculated the technical indicators from historical bars. The database's precomputed technical-indicator table was present. The module recomputed indicators using the existing calculator and cutoff-safe price inputs.

The package index supplied `pypsx==2.8.3`. The SDK's actual `get_ohlcv` signature and daily DataFrame schema were verified from the Windows distribution. Neither pyPSX credential was configured, so no live SDK bars were retrieved or included. The data and artifacts in this report use the existing database only.

## Chronological evaluation

All three experiments trained an XGBoost multiclass classifier and an XGBoost return regressor. The three expanding folds used 7,638 / 5,457, 14,154 / 5,783 and 21,021 / 5,864 training / validation rows. The terminal estimator training signals began on 2022-08-30 and ended on 2025-03-06, with labels through 2025-04-09. The calibration window used signals from 2025-04-17 through 2025-10-17 and labels through **2025-11-14**.

The held-out period starts on **2025-11-24** and ends on **2026-09-15** by signal date. Its last label resolves on **2026-10-13**. The 5,515 test observations cover 51 tickers and include 1,861 bearish, 1,591 sideways and 2,063 bullish outcomes. Purges and embargoes leave some cohort rows outside all terminal partitions.

| Experiment | Mean validation macro F1 | Mean validation RMSE | Held-out macro F1 | Held-out balanced accuracy | Held-out ROC AUC | Held-out log loss | Held-out MAE | Held-out RMSE |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| Technical only | 0.2990 | **12.7713** | 0.1807 | 0.3314 | 0.5282 | 1.1662 | 9.3308 | 12.9642 |
| Fundamental only | 0.2951 | 13.0382 | 0.1815 | 0.3333 | 0.5683 | **1.1420** | **9.2848** | **12.8864** |
| Combined | **0.3134** | 13.7658 | 0.1815 | 0.3333 | 0.5694 | 1.1464 | 9.3493 | 13.0061 |

MAE and RMSE are in percentage points. A zero-return baseline achieved **8.4796 MAE** and **12.3798 RMSE**. All three regressors had higher error. The historical-mean baseline also had lower MAE and RMSE than each model. The combined classifier's held-out accuracy was **37.41%**. It predicted bullish for 5,514 of 5,515 observations, predicted sideways once and issued zero bearish labels. Combined log loss was 1.1186 before recalibration and 1.1464 after recalibration on the same test period. The terminal calibration improved neither combined nor baseline held-out log loss. These results do not establish predictive or trading value.

The financial simulation was unavailable because the price series lacked verified corporate-action-adjusted execution prices. The forecasts are based on raw price returns excluding dividends. Roster selection reflects the stored KSE-100 universe. Original accounting revisions and historical roster membership are unavailable.
